# Victor Décor

Site vitrine pour **Victor Décor**, artisan peintre basé à Saint-Pierre-du-Perray (Essonne, 91).

## Technologies

- HTML5 / CSS3 statique (aucun framework)
- Netlify Forms pour la gestion des demandes de devis

## Lancer localement

```bash
netlify dev --port 8889
```

Ou simplement ouvrir `index.html` dans un navigateur.

## Structure

```
index.html   — page principale
style.css    — feuille de style
merci.html   — page de confirmation après soumission du formulaire
```
